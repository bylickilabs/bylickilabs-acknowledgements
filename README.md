## BYLICKILABS Security Acknowledgements

> Offizielles Repository für Security Acknowledgements, Responsible Disclosure, öffentliche Anerkennung verantwortungsvoller Sicherheitsforschung und zugehörige Informationen für **BYLICKILABS** und **bylickilabs.de**.

> Dieses Repository bietet einen transparenten und strukturierten Ort zur Anerkennung von Personen, die relevante Sicherheitsprobleme in BYLICKILABS Systemen, Websites oder Projekten verantwortungsvoll melden.

━━━━━━━━━━━━ ◆ ━━━━━━━━━━━━

## Über dieses Repository

Sicherheitsforschung ist ein wichtiger Bestandteil bei der kontinuierlichen Verbesserung digitaler Systeme.

Die verantwortungsvolle Meldung von Sicherheitsproblemen trägt dazu bei, Schwachstellen frühzeitig zu erkennen, technisch zu analysieren und koordinierte Maßnahmen zur Behebung einzuleiten.

Dieses Repository dient dazu, entsprechende Beiträge strukturiert zu dokumentieren und Personen öffentlich anzuerkennen, die relevante Sicherheitsprobleme verantwortungsvoll an BYLICKILABS melden.

Die zugehörige öffentliche Acknowledgement Seite ist erreichbar unter:

> [ACKNOWLEDGEMENT](https://bylickilabs.de/security-acknowledgements.html)

## Security Acknowledgements

Personen können für die verantwortungsvolle Meldung sicherheitsrelevanter Erkenntnisse zu BYLICKILABS Infrastruktur, Websites, Anwendungen, Projekten oder anderen ausdrücklich einbezogenen Systemen öffentlich anerkannt werden.

Ein Acknowledgement kann unter anderem folgende Angaben enthalten:

- Name des Security Researchers
- Alias oder Pseudonym
- GitHub Profil
- Website oder berufliches Profil
- Datum der Anerkennung
- Allgemeine Kategorie der Schwachstelle
- Betroffenes BYLICKILABS Projekt oder System
- Aktueller Behebungsstatus
- Optional gewünschte öffentliche Namensnennung

Sensible technische Informationen werden bewusst nicht veröffentlicht, wenn dadurch unnötige Sicherheitsrisiken entstehen könnten.

━━━━━━━━━━━━ ◆ ━━━━━━━━━━━━

## Responsible Disclosure

Sicherheitsrelevante Erkenntnisse sollten vor einer öffentlichen Veröffentlichung zunächst vertraulich und verantwortungsvoll gemeldet werden.

Ein Bericht sollte ausreichend technische Informationen enthalten, damit das beobachtete Verhalten nachvollzogen und soweit möglich reproduziert werden kann.

Verantwortungsvolle Meldungen sollten:

- Das identifizierte Problem eindeutig beschreiben
- Das betroffene System oder die betroffene Komponente benennen
- Mögliche sicherheitsrelevante Auswirkungen erläutern
- Relevante Informationen zur Reproduktion enthalten
- Unnötigen Zugriff auf personenbezogene oder vertrauliche Daten vermeiden
- Destruktive Tests vermeiden
- Beeinträchtigungen produktiver Systeme vermeiden
- Ausreichend Zeit für technische Analyse und Behebung ermöglichen

Eine öffentliche Offenlegung sollte erst nach angemessener Koordination erfolgen, sofern dies erforderlich ist.

━━━━━━━━━━━━ ◆ ━━━━━━━━━━━━

## Anerkennung

Eine öffentliche Anerkennung dient der Würdigung verantwortungsvoller und konstruktiver Sicherheitsforschung.

Eine Anerkennung kann erfolgen, wenn:

- Ein gemeldetes Problem technisch nachvollzogen oder bestätigt werden kann
- Die Meldung ein relevantes BYLICKILABS System oder Projekt betrifft
- Grundsätze verantwortungsvoller Offenlegung eingehalten wurden
- Durch die Untersuchung keine vorsätzlichen Schäden oder unnötigen Beeinträchtigungen verursacht wurden
- Keine vertraulichen oder sensiblen Informationen unangemessen veröffentlicht wurden
- Eine öffentliche Anerkennung für die gemeldete Erkenntnis angemessen ist

Security Researcher können auf Wunsch unter ihrem echten Namen, einem Pseudonym oder einem öffentlichen Profil genannt werden.

Eine anonyme Anerkennung kann ebenfalls möglich sein.

━━━━━━━━━━━━ ◆ ━━━━━━━━━━━━

## Grundsätze der Sicherheitsforschung

BYLICKILABS unterstützt Sicherheitsforschung auf Grundlage von:

- Technischem Verständnis
- Responsible Disclosure
- Reproduzierbarer Analyse
- Respekt vor Privatsphäre
- Schutz sensibler Informationen
- Koordinierter Behebung
- Transparenter Kommunikation
- Ethischer Sicherheitsforschung

Sicherheitsforschung sollte dazu beitragen, Systeme zu verbessern, ohne unnötige Risiken für Nutzer, Infrastruktur oder Dritte zu verursachen.
